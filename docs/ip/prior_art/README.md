# Prior art

One file per invention candidate: `AED-IP-NNN.md`.

**Record close prior art, not only favourable references.** Cherry-picking makes the register
worse than useless: it produces false confidence and wastes attorney time later. A close reference
found now is cheap; the same reference found after filing is not.

Per reference record: the paper, patent, or product; its publication date; a URL or citation; how
it is similar; how the Aedifex approach differs; and what technical limitation the difference
addresses.

If a reference appears to anticipate the approach entirely, say so plainly and record it. That is
a useful finding, not a failure.
