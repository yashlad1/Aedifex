# Public disclosure register

Every external disclosure of Aedifex technical detail, dated. This matters before any patent
strategy discussion, because prior public disclosure constrains the options available.

**"It's only GitHub" is a public disclosure.** So is a portfolio site, a demo video, a pitch deck
shown outside an NDA, a class submission, a thesis, a conference talk, a blog post, or a social
media post describing how something works.

## Before disclosing anything

1. Is there an entry in [INVENTION_REGISTER.md](INVENTION_REGISTER.md) covering it?
2. Is it marked `Patent review required` or listed in
   [TRADE_SECRET_REGISTER.md](TRADE_SECRET_REGISTER.md)?
3. If either, get human approval first. Claude Code must never publish such material.
4. Record the disclosure here afterwards, including what specifically was shown.

This gate applies to open-sourcing code, publishing technical writing, presenting the
architecture, submitting papers, and demos that expose internals. It is not intended to slow
ordinary private development, which is unaffected.
