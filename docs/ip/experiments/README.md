# Experiments

One directory per invention candidate: `AED-IP-NNN/` containing `hypothesis.md`, `method.md`,
`baseline.json`, `results.json`, and `conclusion.md`.

**Record failed experiments too.** A failed approach is often the clearest evidence that the final
implementation is technically non-obvious — it documents what a competent engineer tried first and
why it did not work.

Results must be reproducible: record the dataset version, code commit, model version, prompt
version, and rules version alongside every measurement, per the reproducibility requirement in the
engineering constitution.
